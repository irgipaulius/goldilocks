# Goldilocks

A map for finding the place whose climate is just right.

The current map is Spain, December–February, averaged over 2016–2025. Cells are about 14 km. Temperature and rain are TerraClimate. Cloud is CERES at 1°. The score mixes warmth, clear sky, and dryness, and tiles at or above the 95th percentile are outlined.

Open `spain-winter/index.html`.
